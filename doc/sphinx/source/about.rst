##########################
About pandaict
##########################

pandaict is an easy to use communication network modeling and calculation program that can be used stand-alone, but also connects to pandapower. It uses a high-level ICT network data model to model physical and application layers. 
The NetworkX library `NetworkX <https://networkx.org/documentation/stable/tutorial.html>`_ is used to perform graph-based connectivity, reliability, and bandwith requirement analysis. 
A built-in Monte-Carlo Simulation can be used to calculate reliability and analyse critical components for arbitrary networks. 
It is speed-optimized and using parallel processing based on `numba <https://numba.pydata.org/>`_.
